## 2. 「有趣是相對的」證據摘要

證據強度：中等偏弱，來自個案與媒體轉述，不是系統性調查。

**只有特定國籍覺得新奇（對比樣本）**

| 現象 | 對誰新奇 | 對誰不新奇／反向 |
|---|---|---|
| 戴安全帽進超商 | 日本人（日本被視為強盜行為）。小林賢伍的貼文 | 台灣人視為日常，網友解釋是怕麻煩、天熱 |
| 超商門口堆貨無人看管、離座留包包 | 大阪出身的日本女生覺得不可思議 | 台灣人覺得普通 |
| 垃圾車音樂與追車倒垃圾 | 日本人（日本有固定集中點）、韓國人、英語系都覺得新奇 | 台灣人：第一次有趣，第 340 次就要換你去倒（網友留言，udn） |
| 街上垃圾桶少 | 英語系、中國大陸（小紅書）把「找不到垃圾桶」當衝擊 | 日本街頭其實也少，歐洲人在日本也有同樣驚訝（fullsuitcase https://fullsuitcase.com/japan-culture-shock-things-that-surprised-us/ ），所以這題對台灣人與日本人反而是「共同點」，不是差異 |
| 自動販賣機 | 歐洲人、台灣人覺得日本很多 | 日本人本地不新奇（此點為我推論） |
| 準點電車、禮讓行人 | 台灣人覺得日本準、守禮 | 日本人在台灣則提醒要小心機車與行人 |
| 紙不能丟馬桶 | 日本人（日文旅遊文大量提醒） | 台灣人日常（近年許多場所已能沖） |

**大家都好奇（跨國籍共通）**

- 超商的服務種類（日本人、英語系、中國大陸人都提到，TVBS、justaiwantour、馮氏兄弟）。
- 機車數量（日本人、英語系、韓國人旅客都提到）。
- 垃圾車音樂（日、英、韓各有至少一則）。
- 治安與信任感（英語系、日本人）。

**重要警告：反向命題要小心**
最強的「差異」證據其實是「日本對台灣」與「歐洲／台灣對日本」的好奇點同時出現「垃圾桶少」，這提醒導遊不能只看國籍，要看「家鄉有沒有」這項事物。系統判斷邏輯應該是「使用者家鄉有沒有、做法差多少」，而不是預設「日本人一定覺得 X 新奇」。

## 3. 好奇心出現的情境洞察（推論，非原文）

以下均從貼文內容推論，標「推論」。

1. **在「被迫參與」的瞬間**：垃圾車、超商、MRT 禁飲食，都是旅人必須與它互動才會產生疑問。推論：好奇不是看到就有，而是「我不知道該怎麼做」時最強。
2. **在反差剛出現的第一週**：英語系與日本人的貼文多是「剛來台灣」「第一次」。推論：好奇點有保鮮期，居住久了會變成日常（台灣人說第 340 次就不有趣了）。
3. **看到「人群集體行為」**：追垃圾車、待轉區機車海、晨間太極。推論：群體行為比單一物件更容易被拍下來、發到社群。
4. **與家鄉安全規範衝突時**：戴安全帽進超商、商品無人看守，直接觸發「在我家鄉這代表危險」的警覺。推論：這類「家鄉規則被打破」的好奇度高。
5. **怎麼查**：樣本中，日本人是發 Threads／臉書問在地網友（小林賢伍、日本網友追垃圾車），在地人直接留言解釋。外國人用 Reddit／部落格找旅遊清單（Quora、justaiwantour）。推論：問題通常發在社群上等回答，而不是用搜尋引擎查原因；很多人只是「有感覺沒查」。查不到韓文與英文的原始提問貼文，此為弱推論。
6. **地點**：超商內、馬路路口、住宅區街角（垃圾車）、車站與橋。幾乎都是「路上」與「店內」，不是景點。

## 4. 對產品的建議

**Demo 題目優先序（以台北可現場遇到為前提）**

| 優先 | 題目 | 理由 |
|---|---|---|
| A | 垃圾車音樂／追車倒垃圾 | 日、韓、英都有證據；有故事（德國垃圾車、〈給愛麗絲〉、少女的祈禱，部分仍屬傳聞，Classic FM 說明「健康官員女兒練琴」只是流言，語音要標「據說」）；聽得到聲音，非常適合語音導遊 |
| A | 超商（茶葉蛋、繳費、取貨、煮食） | 跨國籍最穩；站在超商門口就能觸發；日本人對「同樣是超商卻不同」的反差敏感 |
| A | 機車待轉區／機車海 | 日本與英語系都有；紅燈停下時最容易觸發；注意：政策有調整（部分路口取消兩段式左轉），講之前要查最新規定 |
| B | 戴安全帽進超商、商品擺門外（信任感） | 對日本人反差強，但台灣人使用者無感，只對日本家鄉使用者啟用 |
| B | 街上垃圾桶少 | 對英語系／大陸人有效，但對日本家鄉使用者是共通點，用作「你家鄉也一樣」的共鳴題，不算新奇 |
| B | MRT 禁飲食、罰款 | 日本人有文章提到，容易驗證 |
| C | 紙不能丟馬桶 | 實用性高、但近年改變；注意正確性，需分場所 |
| 待驗證 | 騎樓、電線桿、人孔蓋、紅綠燈倒數 | 本次完全沒查到外國人好奇證據。人孔蓋與電線桿是你原本的點子，**可做為差異化，但目前證據不足，Demo 腳本需標示「未驗證」（第二輪補查見 §6：人孔蓋有台灣人蒐集小卡的證據，電線桿與騎樓仍無）** |

**新奇度評分可參考維度**（由本次資料歸納，非現成公式）

1. **家鄉差異度**：使用者家鄉有沒有這個東西？做法差多少？（核心，如超商安全帽、垃圾車）
2. **互動強迫度**：是否會逼使用者參與（如要追垃圾車、要分類）。
3. **群體可見度**：是否有人群行為、聲音或畫面，容易被注意。
4. **規則衝突度**：是否違反使用者家鄉的安全／禮儀直覺。
5. **可驗證度**：導遊能否給出可靠事實，避免傳聞（垃圾車歌曲來源就是反例）。
6. **保鮮期**：久居者疲乏。可用「停留天數」降低重複題目權重。
7. **在地可觸發度**：GPS 是否能偵測到（超商、路口、MRT 站容易；垃圾車要靠時間與聲音推論，難）。

**對 Demo 實作的提醒**：垃圾車不固定，Demo 可以預錄情境或用時段推論，不要假設一定遇得到。
